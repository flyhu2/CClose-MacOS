# 本地验证说明

使用 macOS 14+ 的 AppKit / ScreenCaptureKit 实现；macOS 升级和第三方应用更新后仍需回归。测试通过不代表所有应用已完全兼容。

## 自动检查

```sh
swift test
bash scripts/make_app.sh release
codesign --verify --deep --strict dist/cclose-mac.app
```

21 项测试覆盖坐标、拖动边角、源窗口最小尺寸、鼠标事件字段、浏览器标签排除、过渡帧比例、桌面归属与恢复日志，以及预览内容事件屏蔽和标题栏动作保留。打包前须退出旧实例，退出时会先尝试恢复独立桌面。

## 实际界面检查

使用无用户文档的双窗口测试应用验证真实迁移与渲染。DEBUG 构建有仅针对测试应用的入口和尺寸调整动作；这些入口不进入 release。

- 普通模式与独立桌面：放大、缩小后核对原窗口真实尺寸、文本比例、四边和圆角，不能只看镜像外框。
- 在拖动、停止拖动、原应用重新排版三个阶段检查露底与变形；原窗口自身的空白背景与镜像额外留白应区分。
- 独立桌面默认不透明度 100%；降低后只影响镜像，普通模式始终 100%。
- 存在镜像时关闭独立桌面开关，应取消镜像、迁回该应用窗口、清理工具创建的空桌面。
- 独立模式内容点击、双击、⌘单击、右/中键、拖选、滚轮均不切换桌面、不透传；标题栏长按、拖动、双击、右/中键与边缘缩放仍可用。取消、正常退出、异常重启后检查恢复记录和桌面数量。
- 外部窗口进入工具桌面时应保留桌面；不得删除用户原有桌面。

## 人工验收仍需覆盖

Edge / 编辑器 / 文档应用的快速连续物理拖动、跨显示器与不同缩放倍率、中文输入、弹出菜单、应用最小尺寸、全屏和睡眠唤醒。自动化工具的模拟拖动没有稳定触发全局手势，不能用测试入口替代这部分人工体验验收。独立桌面依赖非公开窗口服务器接口，不能保证未来系统版本保持兼容。

## 2026-11-13 缩放回归

本机调试版在双窗口测试应用中完成独立桌面 500×352 → 580×412 → 500×352。注入停帧并再次放大，超过恢复期限后源窗口撤回 580×412，镜像保留、桌面未切换；解除停帧后可继续缩小。关闭独立开关后两个窗口恢复原桌面，工具桌面删除。捕获尺寸允许不超过 2 像素的取整误差，仍拒绝旧尺寸与错误内容比例。

发布 CI 使用 GitHub 官方 [macOS runner](https://docs.github.com/en/actions/reference/runners/github-hosted-runners) 的 macos-15（arm64）。CI 编译测试不替代原生桌面交互验收。

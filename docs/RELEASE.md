CClose-MscOS 首个版本，由 flyhu2 开发。macOS 14+，Apple Silicon。

- 长按标题栏空白处置顶 / 取消；右键最小化，中键关闭。
- 四边四角调整原窗口尺寸，圆角与可调边框。
- 默认重合模式支持内容交互；独立桌面仅预览，支持 20%–100% 不透明度。
- 独立桌面缩放延迟时保留完整画面；捕获恢复失败则撤回本次缩放，不自动取消置顶。

下载 ZIP，解压移入“应用程序”。授予辅助功能、输入监控、屏幕录制权限后重新打开。更新前退出旧版。

安装包为 ad-hoc 签名，未经过 Apple 公证；确认来源后可在系统设置“隐私与安全性”选择“仍要打开”。无需修改 SIP。

独立桌面会移动目标应用的全部窗口；内容点击和滚轮不回传。非公开桌面接口及自绘标题栏兼容性可能随系统、应用更新变化。参见仓库 README 的使用说明与边界。

鸣谢 Windows 开源项目 [cclose](https://github.com/chaohershi/cclose)（Chaohe Shi）、WindowPin、MoveItHere 与 Hammerspoon。
